    Код бичихээс өмнө вэб яаж ажилладгийг ойлгоё: frontend ба backend, протокол, DNS, хостинг, сайтаа интернэтэд гаргах.

    Энэ хичээлийн дараа

    • Frontend, backend, full-stack-ийн ялгааг тайлбарлаж чадна
    • Хөтөчид хаяг бичихээс хуудас гарах хүртэл юу болдгийг алхам алхмаар хэлж чадна

    01Вэб хөгжүүлэлт гэж юу вэ

    Вэб хөгжүүлэлт гэдэг нь хөтөч (Chrome, Safari, Firefox) дээр ажилладаг сайт, аппликейшнийг бүтээх, засварлах ажил. Нэг вэб апп ихэвчлэн хоёр хэсэгтэй байдаг.

    Мөсөн уулын жишээ. Усан дээр харагдах жижиг хэсэг нь frontend. Усан доор нуугдсан том хэсэг нь backend: хэрэглэгч харахгүй ч бүх ачааг үүрдэг.

    Frontend (клиент тал)Backend (сервер тал)
    Хаана ажилланаХэрэглэгчийн хөтөч дээрСервер дээр
    Юу хийдэгЦэс, товч, слайдер, маягт харагдах ба ажиллах байдалӨгөгдөл хадгалах, боловсруулах, нэвтрэлт, төлбөр
    ТехнологиHTML, CSS, JavaScript; React, Vue, TailwindNode.js, Python, PHP, Java, .NET; MySQL, PostgreSQL, MongoDB

    Full-stack хөгжүүлэгч хоёр талыг хоёуланг нь хийж чаддаг. Frontend хөгжүүлэгчийн заавал эзэмших гурвал бол HTML, CSS, JavaScript; дараа нь тухайн үеийн framework-ийг сурна.

    Технологийн давхарга (stack)

    Хөтөч: HTML · CSS · JS⇄API (HTTP / JSON)⇄Сервер код⇄Өгөгдлийн сан

    Статик ба динамик сайт

    • Статик: бэлэн HTML файлууд, хүн бүрт ижил харагдана. Хурдан, хямд. Жишээ: портфолио, танилцуулга сайт.
    • Динамик: хуудсыг хүсэлт бүрт серверээс өгөгдөл аваад үүсгэнэ. Жишээ: Facebook, онлайн дэлгүүр, банкны апп.

    Өдөр тутмын хэрэгсэл

    Код засварлагч (VS Code), хөтөч ба түүний DevTools (F12), Git ба GitHub, терминал, Figma (дизайн).

    Атом дизайн ба файлын бүтэц

    Атом дизайн нь интерфейсийг жижиг хэсгээс том руу бүтээх арга: атом (товч, input) → молекул (хайлтын хэсэг = input + товч) → организм (header) → загвар → хуудас. Төслийн файлыг ч мөн цэгцтэй байлга:

    04Протоколууд: компьютерууд хэрхэн ярилцдаг вэ

    Протокол гэдэг нь хоёр компьютер мэдээлэл солилцох дүрэм. Хүмүүс нэг хэлээр ярихтай адил.

    TCP/IP давхарга

    ДавхаргаҮүрэгЖишээ

    IP хаяг ба порт

    IP хаяг нь интернэт дэх компьютерийн "гэрийн хаяг". IPv4 нь 32 бит (192.168.1.10), IPv6 нь 128 бит. Порт нь тэр байшингийн "хаалганы дугаар": нэг сервер дээр олон үйлчилгээ зэрэг ажиллана. HTTP 80, HTTPS 443, SSH 22.

    HTTPS = HTTP + TLS шифрлэлт. Нууц үг, картын мэдээлэл замдаа хулгайлагдахгүй. Хаягийн мөрөнд цоож харагдана.

    Бусад чухал протокол: DNS (нэр → IP), SMTP/IMAP (имэйл), FTP/SFTP (файл), SSH (сервер рүү аюулгүй нэвтрэх), WebSocket (бодит цагийн чат).

    05Домэйн ба DNS

    Хүн 142.250.72.14 гэж санахгүй, google.com гэж санана. Домэйн бол IP хаягийн хүнд ойлгомжтой нэр, DNS бол интернэтийн "утасны лавлах".

    1. Хөтөч cache шалгана→2. Resolver (ISP)→3. Root сервер→4. .mn TLD сервер→5. Домэйны NS→6. IP буцаана
    БичлэгҮүрэг
    AДомэйн → IPv4 хаяг
    AAAAДомэйн → IPv6 хаяг
    CNAMEНэг нэрийг өөр нэр рүү заана (www → үндсэн домэйн)
    MXИмэйл хүлээн авах сервер
    TXTБаталгаажуулалт, тохиргооны текст
    NSТухайн домэйныг хариуцах DNS сервер

    Домэйн бүртгүүлэх: нэрээ хайх → бүртгэгч (registrar) сонгох → жил бүр төлөх → DNS бичлэгээ тохируулах.

    Компьютер дээрх кодоо бусад хүн URL-аар нээж болохуйц болгохыг байршуулалт гэнэ.

    Арга 2: Vercel / Netlify

    GitHub repo-гоо холбоно. Цаашид git push хийх болгонд автоматаар шинэ хувилбар гарна. Next.js, React төсөлд хамгийн хялбар.

    Арга 3: VPS дээр гараар

    SSH-ээр нэвтэрч, Nginx суулгаад, файлаа /var/www/ руу хуулна. Хамгийн их хяналттай ч хамгийн их ажилтай.

    Домэйн ба HTTPS

    DNS-д A эсвэл CNAME бичлэг нэмж серверээ заана. HTTPS-ийг Vercel/Netlify автоматаар өгнө; VPS дээр Let's Encrypt (certbot) ашиглана.

    CI/CD: кодоо push хийхэд тест автоматаар ажиллаж (CI), амжилттай бол автоматаар байршина (CD).

    08Нэгтгэл: Enter дарахад юу болдог вэ

    1. Та https://coffee.mn гэж бичээд Enter дарна.
    2. Хөтөч DNS-ээс coffee.mn-ийн IP хаягийг асууна.
    3. Тэр IP-ийн 443 порт руу TCP холболт тогтооно.
    4. TLS handshake хийж, шифрлэсэн суваг үүсгэнэ (HTTPS).
    5. GET / HTTP хүсэлт илгээнэ.
    6. Сервер 200 OK болон HTML буцаана.
    7. Хөтөч HTML-ийг уншаад CSS, JS, зургийг нэмж татна.
    8. DOM ба загварыг нэгтгэж, дэлгэцэнд зурна (render).

    02Веб хэрхэн ажилладаг вэ

    Интернет ба Веб ижил зүйл биш. Интернет бол дэлхийн компьютеруудыг холбосон сүлжээ (зам). Веб бол тэр сүлжээгээр дамждаг хуудаснуудын систем (зам дээгүүр явах машин). Имэйл, тоглоом ч интернетээр явдаг ч веб биш.

    1. URL бичнэ→2. DNS → IP→3. Сервер рүү хүсэлт→4. HTML ирнэ→5. CSS, JS, зураг татна→6. Дэлгэцэнд зурна

    03HTML: тэг, элемент, атрибут

    HTML = HyperText Markup Language. HyperText гэдэг нь холбоосоор нэг хуудаснаас нөгөө рүү үсрэх текст; Markup гэдэг нь текстэд "энэ гарчиг", "энэ жагсаалт" гэж тэмдэг тавих. HTML бол програмчлалын хэл биш, тэмдэглэгээний хэл.

    элементийн бүтэц
    <p class="intro">Сайн уу, би Урсаа!</p>

 нээх тэг

Нээх тэг + агуулга + хаах тэг = ЭЛЕМЕНТ

    Хоосон (void) элемент

    Зарим элемент агуулгагүй тул хаах тэггүй: <br> (мөр шилжүүлэх), <hr> (хэвтээ шугам), <img>, <input>, <meta>, <link>.

    05Гарчиг ба догол мөр

    <h1>-ээс <h6> хүртэл 6 түвшний гарчиг бий. Хуудсанд нэг л h1 байх нь зөв. Түвшнийг алгасахгүй: h1 → h2 → h3. Текстийг томруулах гэж гарчиг бүү ашигла, томруулах нь CSS-ийн ажил.

    <b>, <i> ч тод, налуу харагдана, гэхдээ утга агуулахгүй. Дэлгэц уншигч (хараагүй хүний программ) strong, em-ийг онцолж уншдаг тул эдгээрийг илүүд үз.

    07Жагсаалт: ul, ol, li

    • <ul> (unordered): дараалал чухал биш, цэгтэй
    • <ol> (ordered): дараалал чухал, дугаартай
    • <li>: жагсаалтын нэг мөр; заавал ul эсвэл ol дотор
